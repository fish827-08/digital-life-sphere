# L9 尸体能量守恒 + L8 地形 + 季节系统 设计文档

> 分支：`feature/l9-terrain-season` | 版本：v0.7 | 日期：2026-09-08

## 一、概述

本次开发在数字生命模拟系统中新增三大生态特性，全部默认关闭（`enabled=False`），开启后自动回退 Python 路径（Rust 下沉为后续工作）：

| 特性 | 核心目标 | 关键机制 |
|------|---------|---------|
| **L9 尸体能量守恒** | 死亡能量不凭空消失，形成完整生态循环 | 死亡→尸体→食腐→分解→资源 |
| **L8 地形（简化版）** | 空间异质性第二维度，创造地理屏障 | 水域不可通行 + 山地高能耗 |
| **季节系统** | 时间异质性，迫使生物跨纬度迁移 | 太阳直射点摆动 + 冬季资源贫瘠 |

## 二、L9 尸体能量守恒

### 2.1 设计动机

原系统中，饿死/老死个体的能量和胃粮全部凭空消失，捕食猎物的剩余能量（1-transfer_ratio=60%）也凭空消失。这破坏了能量守恒，且缺失了"食腐"这一重要生态位。

### 2.2 能量流

```
死亡个体（energy + stomach）
    │
    ▼ carcass_ratio（默认 0.8）
尸体场 _carcass[flat]
    │
    ├──► 食腐：同格生物食用 × scavenge_digestibility（0.7）→ 胃粮
    │
    └──► 自然分解：每 tick × decomposition_rate（0.002）
            │
            ▼ resource_conversion（0.5）
        食物资源场（其余 50% 为分解损耗）
```

### 2.3 能量守恒方程

每 tick 总能量变化：
```
ΔE_total = 光合输入 - 代谢/维持/移动/攻击消耗
         - 尸体分解损耗（decompose × (1 - resource_conversion)）
         - 食腐消化损耗（carcass_eaten × (1 - scavenge_digestibility)）
```

死亡本身不创造或销毁能量：死亡个体的 `carcass_ratio` 部分进入尸体场，剩余 `1 - carcass_ratio` 为不可食用部分（骨骼/甲壳等，视为代谢损耗）。

### 2.4 配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `enabled` | False | 总开关 |
| `carcass_ratio` | 0.8 | 死亡能量转化为尸体的比例 |
| `scavenge_digestibility` | 0.7 | 食腐消化率（低于新鲜食物） |
| `decomposition_rate` | 0.002 | 尸体每 tick 自然分解比例（约 500 tick 完全分解） |
| `resource_conversion` | 0.5 | 分解的尸体转化为食物的比例 |
| `scavenge_joy` | 0.003 | 食腐愉悦度权重（预留，当前未接入愉悦度） |

### 2.5 实现要点

- **死亡转尸体**：在步骤7死亡判定后、步骤8繁殖前，统一处理。所有死因（饿死/老死/被捕食）的剩余能量 × carcass_ratio + 胃粮 × carcass_ratio 累加到同格尸体场。
- **食腐**：在步骤4进食后，有胃容量剩余的个体食用同格尸体。同格多只时均分（与 consume_many 同样的均分逻辑）。食用量 = 进食量 × 0.5（食腐效率低于新鲜食物）。
- **尸体分解**：在 `_advance_one_tick` 的资源再生后，每 tick 尸体 × decomposition_rate 分解，其中 × resource_conversion 转化为食物资源。
- **快照**：尸体场保存/恢复，快照版本升级到 v3。

## 三、L8 地形系统（简化版）

### 3.1 设计动机

原系统是均匀球面，只有 L1 斑块资源提供空间异质性。地形系统提供第二个空间维度：水域作为不可通行的地理屏障，山地作为高能耗区域，创造生态位分化和迁移通道。

### 3.2 简化设计

与 L8-L10 文档中的完整版（值噪声 + 5 种地形 + 温度偏移）不同，本次实现采用简化版：

- **生成方式**：纬度带偏置 + 随机斑块，不用值噪声
- **地形类型**：3 种（平原/山地/水域），不做森林/沙漠
- **静态**：世界生成时固定，不随时间变化
- **独立种子**：`seed + 7` 派生，不消费引擎 rng

### 3.3 地形效果

| 地形 | 占比 | 可通行 | 移动能耗 | 资源再生 |
|------|------|--------|---------|---------|
| 平原 | 剩余 | 是 | ×1.0 | ×1.0 |
| 山地 | mountain_ratio | 是 | ×mountain_move_mult（2.0） | ×mountain_regrow_mult（0.3） |
| 水域 | water_ratio | **否** | — | ×0.0 |

### 3.4 极地水域偏置

`water_pole_bias`（默认 0.5）控制极地水域概率加成：
- 水域概率 = water_ratio × (1 + water_pole_bias × |纬度|)
- 0 = 均匀随机，1 = 极地水域概率 ×2
- 模拟"极地冰原/海洋"的自然分布

### 3.5 配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `enabled` | False | 总开关 |
| `water_ratio` | 0.08 | 水域目标占比 |
| `mountain_ratio` | 0.12 | 山地目标占比 |
| `mountain_move_mult` | 2.0 | 山地移动能耗倍率 |
| `mountain_regrow_mult` | 0.3 | 山地资源再生倍率 |
| `water_pole_bias` | 0.5 | 极地水域概率加成 |

### 3.6 实现要点

- **移动过滤**：在 Python 路径的移动决策中，邻居列表过滤掉水域格。如果所有邻居都是水域，则不移动。
- **山地能耗**：移动到目标格后，移动能耗 × 目标格地形倍率。
- **资源再生**：地形 regrow_mult 与季节因子相乘，作为额外再生倍率传入 ResourceField.regrow。
- **出生位置**：初始个体和子代只在可通行格出生（子代在亲代位置，亲代必在可通行格）。

## 四、季节系统

### 4.1 设计动机

原系统太阳固定在赤道，只有昼夜没有季节。季节系统引入黄赤交角，太阳直射点随季节在南北纬之间摆动，导致冬季半球资源贫瘠、植物光合降低，迫使生物跨纬度迁移。

### 4.2 核心机制

**太阳直射纬度**（渐进变化，非突变）：
```
sun_lat(tick) = axial_tilt × sin(2π × tick / year_ticks)
```
- 春分（tick=0）：太阳直射赤道
- 夏至（tick=year_ticks/4）：太阳直射北回归线（+axial_tilt）
- 秋分（tick=year_ticks/2）：太阳直射赤道
- 冬至（tick=3×year_ticks/4）：太阳直射南回归线（-axial_tilt）

**光照公式**（加入太阳直射纬度）：
```
光照 = cos(纬度 - sun_lat)^lat_base_ref × max(0, cos(经度差))
```

**季节因子**（用于资源再生和光合）：
```
season_factor = clip(cos(纬度 - sun_lat) / cos(纬度), winter_floor, 1.0)
```
- 冬季半球：cos(纬度 - sun_lat) < cos(纬度) → 因子 < 1（最低 0.3）
- 夏季半球：cos(纬度 - sun_lat) > cos(纬度) → 因子被 clip 到 1.0（不增强，保持能量守恒）
- 赤道附近：因子 ≈ 1.0（全年变化小）

### 4.3 渐进性保证

用户明确要求"季节变换引起的资源减少是渐进的，符合自然规律，不是马上就减少"。本实现通过以下方式保证渐进性：

1. **太阳直射纬度是 sin 函数**：连续可导，变化率在春分/秋分最大、夏至/冬至最小，无突变。
2. **季节因子基于 cos 比值**：平滑函数，无阶跃。
3. **clip 只限制范围**：clip 到 [0.3, 1.0] 不会导致跳变（函数本身连续）。
4. **资源再生率 = 基准 × 温度因子 × 季节因子 × 地形因子**：所有因子都是平滑的，总再生率渐进变化。

### 4.4 数值平衡：生物寿命与季节周期

用户要求"确保生物至少可以体验几个完整的四季"。

**当前参数**：
- 世界自转 = 2400 tick = 1 世界日
- 生物寿命 = 1~8 世界日（g3 决定，平均 ≈ 4.5 世界日）
- 一年 = year_length × 2400 tick

**默认 year_length = 3**（一年 = 3 世界日 = 7200 tick）：
| g3 | 寿命（世界日） | 体验年数 |
|----|---------------|---------|
| 0.0 | 1 | 0.33 |
| 0.3 | 3.1 | 1.03 |
| 0.5 | 4.5 | 1.5 |
| 0.7 | 5.9 | 1.97 |
| 1.0 | 8 | 2.67 |

- 大部分生物（g3 > 0.3，寿命 > 3.1 世界日）可体验至少 1 个完整四季
- 长寿生物（g3 > 0.7）可体验 2~3 个四季
- 短命生物（g3 < 0.3）只能体验季节变化方向，但这是自然选择的一部分（短命物种可能采取 r 策略，不需要感知季节）

**调整建议**：
- 希望生物体验更多四季 → 增大 year_length（如 4~6）或延长生物寿命
- 希望季节变化更快、选择压强 → 减小 year_length（如 2）
- 生物寿命公式在 `OrganismConfig` 中通过 `g3` 基因间接控制，修改寿命公式会影响整个系统平衡，建议优先调整 year_length

### 4.5 配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `enabled` | False | 总开关 |
| `year_length` | 3 | 一年 = 多少世界日 |
| `axial_tilt` | 0.4 | 黄赤交角（弧度，约 23°） |
| `winter_regrow_mult` | 0.3 | 冬季半球资源再生倍率下限 |
| `winter_photo_mult` | 0.3 | 冬季半球植物光合倍率下限（当前与 season_factor 统一） |

### 4.6 实现要点

- **光照温度**：`LightAndTemperature` 新增季节参数，`_ensure_cache` 中 Python 路径的光照公式加入太阳直射纬度。季节启用时不使用 Rust 加速版（Rust 版不支持季节参数）。
- **资源再生**：`_advance_one_tick` 中，季节启用时计算 `season_factor`，与地形 `regrow_mult` 相乘后作为 `extra_mult` 传入 `ResourceField.regrow`。
- **植物光合**：步骤1光合和植物化增强中，光照 × `season_factor[flat]`。
- **新增方法**：`sun_latitude(tick)` 返回太阳直射纬度，`season_factor(tick)` 返回每格季节因子。

## 五、Rust 路径兼容

当 `carcass.enabled` / `terrain.enabled` / `season.enabled` 任一为 True 时，引擎自动将 `use_sim_core` 设为 False，回退 Python 路径。

**原因**：
1. L9 尸体的死亡转化、食腐、分解需要在 Python 侧统一处理
2. L8 地形的移动过滤、山地能耗需要修改移动决策逻辑
3. 季节系统需要修改光照温度计算，Rust 版 `LightTempRust` 不支持季节参数

**后续工作**：三大功能稳定后，可逐步下沉到 Rust（优先级：季节光照 > 尸体分解 > 地形移动）。

## 七、对语言涌现的潜在影响

1. **地形屏障**：水域创造地理隔离，可能导致种群分化和方言形成（语言涌现的必要条件）。
2. **季节迁移**：冬季资源贫瘠迫使生物跨纬度迁移，增加了不同种群接触的机会，可能促进文化交流和信号传播。
3. **尸体信号**：尸体位置天然具有"危险/食物"的信号意义，未来可扩展为"死亡信号"，丰富信号语义。
4. **食腐生态位**：食腐行为创造了新的社会互动场景（围绕尸体的竞争/合作），可能促进协作信号的演化。

## 八、已知限制与后续工作

1. **Rust 下沉**：当前三大功能仅在 Python 路径实现，性能低于 Rust 路径。大世界长实验需要 Rust 下沉。
2. **地形复杂度**：简化版只有 3 种地形，没有森林/沙漠/温度偏移。后续可扩展值噪声生成。
3. **尸体信号**：当前尸体只是能量载体，没有信号意义。后续可加入"死亡信号"（尸体位置自动产生危险标记）。
4. **食腐基因**：当前所有个体都能食腐，没有食性分化。后续可用 g17 预留位做食性基因（植食/肉食/食腐偏好）。
5. **季节愉悦度**：当前季节只影响资源和光合，没有直接影响愉悦度。后续可加入"季节情感"（冬季抑郁/夏季愉悦）。
